# preview/ — צפייה ובדיקה מקומית של ה-HTML, בלי שרת

התיקייה הזו נועדה בשביל דבר אחד: לפתוח קובץ HTML ישירות בדפדפן (לחיצה
כפולה, או גרירה לחלון דפדפן פתוח) ולראות/לבדוק אותו — בלי להריץ Python,
בלי .env, בלי תלויות. שני הקבצים:

## `onboarding_preview.html` — אשף ההרשמה, מלא ואינטראקטיבי

זהו עותק מדויק של `../app/templates/onboarding.html`. אפשר לעבור על כל
4 השלבים, למלא טפסים, לבדוק ולידציות (למשל מספר טלפון לא תקין), ואפילו
ללחוץ "סיום הרשמה" ולראות את מסך הסיום — כולל **מספר הסוכן האמיתי** שלכם
(`READER_WHATSAPP_NUMBER` מה-`.env`, מוטבע בקובץ בזמן יצירת התצוגה המקדימה)
וכפתור ההעתקה. הכול עובד, כי הקובץ מזהה אוטומטית שהוא נפתח מהדיסק (`file://`)
ומדמה את שאר התשובות מהשרת במקום לפנות אליו באמת. תראו באנר כחול למעלה
שמזכיר שזו תצוגה מקדימה. שום דבר לא נשמר לשום מקום.

## `dashboard_preview.html` — פאנל הניטור, עם נתוני דוגמה קבועים

בניגוד לאשף ההרשמה, פאנל הניטור (`dashboard.html`) הוא תבנית Jinja2
שמצפה לנתונים אמיתיים מהשרת — אי אפשר לפתוח אותו ישירות. הקובץ הזה הוא
"צילום מסך חי" שלו: אותו CSS/HTML בדיוק, ממולא בהודעות/הפרות/התראות
לדוגמה, כדי שתוכלו לראות איך זה נראה. הכפתורים "נכון/טופל" ו"שגוי" לא
פעילים כאן (הם קוראים ל-API שלא קיים כשאין שרת).

## איך לפתוח

**אופציה א' — מהפינדר:** לחיצה כפולה על הקובץ תפתח אותו בדפדפן ברירת
המחדל.

**אופציה ב' — מהטרמינל:**
```bash
open "preview/onboarding_preview.html"      # macOS
open "preview/dashboard_preview.html"
```

## אחרי שעורכים את התבניות האמיתיות

אם שיניתם משהו ב-`app/templates/onboarding.html` או `app/templates/dashboard.html`,
או אם עדכנתם את `READER_WHATSAPP_NUMBER` ב-`.env` ורוצים שהמספר החדש יופיע
גם בתצוגה המקדימה — הריצו מחדש:
```bash
../.venv/bin/python3 preview/regenerate.py
```
(דורש את התלויות המלאות של הפרויקט — לא רק `jinja2` — כי הסקריפט קורא את
ה-`.env` דרך `app/config.py`; לכן מריצים דרך `.venv` ולא Python מערכת סתם.)

## לבדיקה עם נתונים אמיתיים ולא לדוגמה

זה מה שהשרת האמיתי בשביל — `../scripts/run_core.sh` ואז
`http://localhost:8000/onboarding` ו-`http://localhost:8000/dashboard`.
ראו את ה-README הראשי (`../README.md`) להוראות המלאות.
